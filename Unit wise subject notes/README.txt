UNIT WISE SUBJECT NOTES
One folder per subject; one PDF per unit = detailed notes of the unit + every important question of the unit with its marks.

HRM/      HRM_Unit_1..4_Detailed_Notes_and_Important_Questions.pdf        (rebuild: python -I tools/make_hrm_unit_notes.py)
Finance/  Finance_Unit_1..4_Detailed_Notes_and_Important_Questions.pdf    (rebuild: python -I tools/make_fin_pdfs.py)
Marketing/ Marketing_Unit_1..4_Detailed_Notes_and_Important_Questions.pdf  (rebuild: python -I tools/make_mkt_pdfs.py)

Part A = detailed notes. Part B = questions grouped by marks (2, 3, 5, 6, 10), star rating, and the Part A section to read. Part C (HRM, Finance, Marketing; added 21 Nov 2026) = the PUT paper 2026-27 questions of the unit, the practice numericals and the theory bank, each with its full model answer.

Expanded_Notes_and_Answers PDFs (added 20-21 Nov 2026, in each subject folder) = fuller notes plus fully written answers for the unit; kept as you supplied them. They are not generated by the tools in this repository.
